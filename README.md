TITLE
Beyond Node Degree: Identity Collapse and Edge-Weight Concentration in Graph-Based Network Intrusion Detection

ABSTRACT (233 words)
Graph-based network intrusion detection almost universally represents attacker behavior through node-centric structural features – degree, centrality, embeddings from graph neural networks – which implicitly assume that an attacker's identity is visible as a distinct node in the host-communication graph. We show that this assumption breaks under a common, realistic condition: network address translation (NAT) or perimeter aggregation, which collapses many real hosts onto a small number of gateway addresses. Using real, labeled flow data from the CICIDS2017 benchmark (Friday afternoon distributed denial-of-service capture, 225,745 flows), we construct time-windowed directed host-communication graphs and show that the attack, once NAT-collapsed to a single source-destination pair, is statistically indistinguishable from benign traffic under standard node-degree features (Mann-Whitney p = 0.12–0.83 across four window sizes from 60 seconds to 10 minutes) while a simple edge-weight concentration feature separates attack from benign windows perfectly (area under the rank-biserial curve = 1.00, p < 10⁻⁴ at every window size tested). At the individual-flow level, this lightweight, ten-dimensional graph-context feature set matches the detection performance of the standard 78-dimensional CICFlowMeter feature set (F1 = 1.000 vs. 0.9995–0.9983) while requiring 5–10× less classifier training time. We report this result honestly as a single-attack-type case study: the identity-collapse robustness argument is conceptually general, but empirical validation against other attack archetypes (reconnaissance, beaconing, slow multi-host infiltration) is needed before the claim can be generalized, and we describe exactly what that validation would require.

KEYWORDS
network intrusion detection, graph-based anomaly detection, host-communication graphs, structural features, network address translation, CICIDS2017
